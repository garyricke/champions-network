Starting a new chapter

Mark expects Missouri next. Everything on this page regenerates from one JSON file per chapter — no layout work required.

  1. Upload the venue photo to Cloudinary:
    node print-build/cloudinary-upload.js ~/Downloads/photo.jpeg <slug>-venue
  2. Copy chapter-kit/chapters/boulder.json to <slug>.json and edit the fields — venue, address, chapter lead, meeting day and time, and the session dates.
  3. Run node print-build/build-chapter-kit.js <slug>.
  4. Commit and push. Netlify serves the new landing page at champions-network.com/<slug>, and it appears on this page automatically.
